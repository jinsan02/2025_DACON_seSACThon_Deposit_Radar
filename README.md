# 🛡️ Deposit Radar: AI 기반 전세사기 예방 리포트 엔진

> **2025 새싹 해커톤 프로젝트 (팀 Deposit Radar)**
> **담당 역할:** AI/LLM 및 자동화 엔지니어링 (기여도 100% - 해당 파트)

## 1. 프로젝트 개요
등기부등본의 변동 사항을 감지하여, 임차인에게 **위험 등급(Risk Grade)**을 알리고 **맞춤형 대응 가이드(Playbook)**를 PDF로 자동 생성해주는 서비스입니다.

## 2. 담당 기능 및 구현 내용
### 🤖 AI 플레이북 엔진 (`core/llm_engine.py`)
- **등급별 시나리오 분기:** RED/AMBER/GREEN 등급에 따라 프롬프트와 대응 전략을 동적으로 변경.
- **페르소나 적용:** '부동산 법률 전문가' 페르소나를 적용하여 신뢰도 높은 톤앤매너 구현.
- **RAG(검색 증강 생성) 적용:** 2025년 최신 전세사기 특별법 및 지원 정책(LH 경매차익 등)을 프롬프트에 주입.

### 📄 PDF 생성 파이프라인 (`core/pdf_maker.py`, `templates/report.html`)
- **WeasyPrint & Jinja2:** HTML/CSS 기반의 고품질 PDF 렌더링 시스템 구축.
- **동적 레이아웃:** 내용 길이에 따라 페이지가 자동으로 넘어가는 '스마트 레이아웃' 및 'Q&A 잘림 방지' 구현.
- **시각화:** 위험 등급에 따른 테마 색상 자동 변경 및 타임라인/도표 시각화.

## 3. 기술 스택
- **Language:** Python 3.11
- **AI:** OpenAI API (GPT-4o-mini / GPT-5-nano)
- **Framework:** FastAPI (비동기 처리)
- **Libs:** WeasyPrint, Jinja2, Pydantic

## 4. 성과
- 복잡한 등기부 데이터를 일반인도 이해하기 쉬운 **3단 구성 리포트(요약-분석-행동)**로 시각화.
- **API 비용 최적화:** 일반 분석엔 경량 모델(Mini), 심층 분석엔 고성능 모델을 사용하는 이원화 전략 수립.
