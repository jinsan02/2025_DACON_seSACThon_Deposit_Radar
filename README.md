# 🛡️ Deposit Radar: AI 기반 전세사기 예방 리포트 엔진

> **2025 새싹 해커톤 프로젝트 (팀 Deposit Radar, 4인)** · 예선 14위 본선 진출
> **담당 역할:** AI/LLM 엔진부터 PDF 리포트 생성까지

## 1. 프로젝트 개요
등기부등본의 변동 사항을 감지하여, 임차인에게 **위험 등급(Risk Grade)**을 알리고 **맞춤형 대응 가이드(Playbook)**를 PDF로 자동 생성해주는 서비스입니다.

## 2. 담당 기능 및 구현 내용
### 🤖 AI 플레이북 엔진 (`core/llm_engine.py`)
- **규칙 기반 등급 판정:** 등기부 변동 키워드로 RED/AMBER/GREEN을 판정한다. `가압류`가 `압류`로 잘못 잡히지 않도록 검사 순서를 고정했다.
- **등급별 고정 경고 + LLM 서술:** 법률 정보가 틀리면 사용자가 손해를 볼 수 있어, 등급별 핵심 경고(전출 금지, 배당요구종기일, 갱신 거절 통보 시점 등)는 프롬프트에 고정 문안으로 넣고 LLM은 상황 요약·체크리스트·Q&A를 JSON으로만 작성하게 했다.
- **페르소나 적용:** '부동산 법률 전문가' 페르소나를 적용하여 신뢰도 높은 톤앤매너 구현.
- **면책 문구:** 리포트에 `AI 분석 결과이며 법적 효력이 없다`는 안내를 넣었다.
- 검색 증강 생성(RAG)은 구현하지 않았다. 최신 정책 문서를 검색해 근거로 붙이는 확장은 해커톤 멘토에게 받은 다음 단계 피드백이다.

### 📄 PDF 생성 파이프라인 (`core/pdf_maker.py`, `templates/report.html`)
- **WeasyPrint & Jinja2:** HTML/CSS 기반의 고품질 PDF 렌더링 시스템 구축.
- **동적 레이아웃:** 내용 길이에 따라 페이지가 자동으로 넘어가는 '스마트 레이아웃' 및 'Q&A 잘림 방지' 구현.
- **시각화:** 위험 등급에 따른 테마 색상 자동 변경 및 타임라인/도표 시각화.

## 3. 기술 스택
- **Language:** Python 3.11
- **AI:** OpenAI API (`gpt-4o-mini`)
- **Framework:** FastAPI (비동기 처리)
- **Libs:** WeasyPrint, Jinja2, Pydantic

## 4. 성과
- 복잡한 등기부 데이터를 일반인도 이해하기 쉬운 **3단 구성 리포트(요약-분석-행동)**로 시각화.
- 무박 일정에서 MVP 범위로 등급 판정부터 PDF까지 한 흐름을 완성하고 RED·AMBER·GREEN 샘플 리포트를 생성했다.
- 경량·고성능 모델을 나눠 쓰는 비용 전략은 계획 단계에 그쳤고, 현재 코드는 `gpt-4o-mini` 한 모델을 호출한다.
